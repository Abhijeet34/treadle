# Provenance

This file records how treadle was built, so that anyone auditing the licence position can check it rather than take it on trust.

## The short version

treadle is an independent implementation.
It contains no code from any other project.
No third-party notice attaches to it, and `NOTICE` says so.

## Prior art we studied

treadle is a successor in capability to `tasks-axi`, a task-backlog command-line tool that edits a single markdown file in place and prints compact structured output for agents.
It is one author's own earlier tool.
We studied it, and we carried none of it.

We also read the following published specifications and used them as sources for behaviour that is nobody's invention: the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0), [RFC 3339](https://www.rfc-editor.org/rfc/rfc3339) for instants, [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180) for CSV, [Semantic Versioning 2.0.0](https://semver.org/), [Conventional Commits 1.0.0](https://www.conventionalcommits.org/), [Unicode Standard Annex #11](https://www.unicode.org/reports/tr11/) for display width, [the NO_COLOR convention](https://no-color.org/), [clig.dev](https://clig.dev/), [POSIX XBD 12.2](https://pubs.opengroup.org/onlinepubs/9699919799/basedefs/V1_chap12.html) for utility argument syntax, and [OWASP](https://owasp.org/) guidance on CSV injection and prototype pollution.
Conforming to a published standard is not derivation from an implementation of it.

## The process, and why it produces a clean result

The design was written before any code, in five audit phases, by people who read the prior art so that the person writing the code did not have to.

1. A teardown of the prior art, describing its behaviour in the auditor's own words and citing it only by file and line, carrying no source, identifiers, help text, command names, flag names, error strings or file-format keys out of it.
2. A domain model designed from how a scrum or kanban team works, not from what the prior art happened to implement.
3. Eight architecture decision records, each with the alternatives it measured and the number that rejected each.
4. An interface specification with measured output budgets.
5. A threat model with thirteen findings, each naming its fix and where it lands.

The implementation was written against those five documents.
The prior-art tree was never opened by the implementer, and the auditors' evidence file, which holds verbatim command lines and output from the prior art, was withheld from the implementer for the same reason.

Where the design deliberately shares a word with the prior art, the auditors said so rather than leaving it to be discovered.
The state names (`draft`, `ready`, `in_progress`, `in_review`, `done`, `on_hold`, `cancelled`) are common industry vocabulary and two of them also appear in the prior art; renaming them to avoid a coincidence would make the names worse, which is the wrong trade.
The same applies to `show`, `--reason` and `--fields`: each is the ordinary word for its job, and a shared ordinary word is a convention rather than a borrowing.

## Properties we adopted, and expression we did not

Several properties of the prior art were judged worth having and were reimplemented from a description of the property, never from its code: idempotent mutations that say so, confirmation-forward output, typed errors carrying a code and a runnable next step, truncation that names the true size, referential integrity checked on write, all-or-nothing multi-item mutations, and documentation generated from the tool's own contract so it cannot drift.

A property is not copyrightable and an expression is.
Every line in this repository is this project's own expression of a property it chose to have.

## Machine-detectable origin marks

Nothing in this repository carries a marker whose purpose is to let a machine classify how it was produced: no invisible or zero-width codepoints, no steganographic marker, no "generated by" tag.
Provenance a reader uses, which is this file, the commit history, and the `Signed-off-by` trailer every commit carries, is kept in full.
